# Пользовательские сценарии

## Первый запуск

1. Пользователь пишет `/start`.
2. Бот проверяет Telegram user id.
3. Если id разрешен, бот показывает меню:

```text
Что делаем?
```

Кнопки:

- `Найти`
- `Список`
- `Статистика`

4. Если id не разрешен, бот отвечает отказом.

## Поиск и добавление фильма

1. Пользователь пишет:

```text
/search Интерстеллар
```

2. Бот ищет тайтлы в ПоискКино API.
3. Бот показывает до 5 результатов.
4. Пользователь нажимает `Добавить`.
5. Бот сохраняет запись и отвечает:

```text
Добавлено: Интерстеллар, 2014
```

## Поиск обычным текстом

1. Пользователь пишет:

```text
Во все тяжкие
```

2. Если сообщение не является командой и не относится к редактированию, бот считает его поисковым запросом.
3. Дальше сценарий такой же, как у `/search`.

## Защита от дублей

1. Пользователь пытается добавить тайтл, который уже есть в базе.
2. Бот не создает вторую запись.
3. Бот отвечает:

```text
Этот тайтл уже есть в списке.
```

Кнопки:

- `Открыть`
- `Отмена`

## Просмотр списка

1. Пользователь пишет `/list`.
2. Бот показывает первую страницу списка.
3. На странице 10 записей.
4. Если записей больше 10, бот показывает пагинацию:

- `Назад`
- `Вперед`

## Редактирование записи

1. Пользователь открывает запись из списка.
2. Бот показывает карточку тайтла и кнопки:

- `Статус`
- `Оценка`
- `Заметка`
- `Дата`
- `Удалить`

3. Пользователь выбирает действие.
4. Бот запрашивает новое значение или показывает inline-кнопки.
5. Бот сохраняет изменение.

## Изменение оценки

1. Пользователь нажимает `Оценка`.
2. Бот показывает кнопки `1` - `10`.
3. Пользователь выбирает оценку.
4. Бот обновляет запись.

## Удаление записи

1. Пользователь нажимает `Удалить`.
2. Бот спрашивает подтверждение.
3. Пользователь нажимает `Да, удалить`.
4. Бот удаляет запись.

## Ошибка ПоискКино API

Если API недоступен или вернул ошибку, бот отвечает:

```text
Не получилось выполнить поиск. Попробуйте позже.
```

В логах нужно сохранить техническую причину ошибки.
