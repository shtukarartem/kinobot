# План разработки

## Этап 1. Каркас проекта

- Инициализировать Node.js проект.
- Подключить TypeScript.
- Настроить ESLint и Prettier.
- Добавить запуск в dev-режиме.
- Добавить чтение `.env`.

Готово, когда приложение стартует командой:

```bash
npm run dev
```

## Этап 2. Telegram bot

- Подключить Telegraf.
- Реализовать `/start`.
- Реализовать middleware доступа.
- Добавить глобальный обработчик ошибок.

Готово, когда разрешенный пользователь получает меню, а остальные получают отказ.

## Этап 3. База данных

- Подключить PostgreSQL.
- Добавить ORM.
- Описать модели `User`, `Title`, `WatchEntry`.
- Создать миграцию.
- Добавить seed разрешенных пользователей при первом взаимодействии.

Готово, когда бот может сохранить пользователя и тестовую запись.

## Этап 4. Поиск

- Реализовать `PoiskKinoClient`.
- Добавить `/search`.
- Показать результаты inline-кнопками.
- Обработать пустые результаты и ошибки API.

Готово, когда пользователь может найти фильм или сериал по названию.

## Этап 5. Добавление в список

- Реализовать callback `add:<poiskkinoId>`.
- Сохранять `Title`.
- Создавать `WatchEntry`.
- Проверять дубли.

Готово, когда выбранный тайтл появляется в списке.

## Этап 6. Просмотр списка

- Реализовать `/list`.
- Добавить пагинацию.
- Добавить карточку записи.

Готово, когда можно удобно смотреть общий список.

## Этап 7. Редактирование

- Изменение статуса.
- Изменение оценки.
- Изменение заметки.
- Изменение даты просмотра.
- Удаление с подтверждением.

Готово, когда запись можно полностью поправить из Telegram.

## Этап 8. Полировка

- Добавить `/help`.
- Добавить `/stats`.
- Улучшить форматирование сообщений.
- Добавить тесты сервисов.
- Добавить README с командами запуска.

## Минимальный порядок реализации

1. Конфиг и запуск.
2. Доступ.
3. Поиск.
4. База.
5. Добавление.
6. Список.
7. Редактирование.
